# Gmail API Setup — one-time steps

This connects the Streamlit app directly to `blocktrades32@gmail.com` so it can poll for new CME emails on its own. You only do this once. It takes about 10 minutes.

## 1. Create a Google Cloud project

1. Go to https://console.cloud.google.com/
2. Sign in with the `blocktrades32@gmail.com` account (or whichever Google account owns that inbox)
3. Click the project dropdown at the top → **New Project**
4. Name it something like `blocktrades-headlines` → **Create**
5. Make sure the new project is selected in the dropdown before continuing

## 2. Enable the Gmail API

1. In the search bar at the top, type **Gmail API** and open it
2. Click **Enable**

## 3. Configure the OAuth consent screen

1. Left menu → **APIs & Services** → **OAuth consent screen**
2. User type: **External** → Create
3. Fill in the required fields (app name, e.g. "Block Trade Headlines"; your email for support/developer contact)
4. On the **Scopes** step, click **Add or Remove Scopes**, search for and add:
   - `https://www.googleapis.com/auth/gmail.readonly`
5. On the **Test users** step, add `blocktrades32@gmail.com` as a test user
6. Save through to the end (you don't need to submit for verification — test mode is fine for personal use)

## 4. Create OAuth credentials

1. Left menu → **APIs & Services** → **Credentials**
2. **Create Credentials** → **OAuth client ID**
3. Application type: **Desktop app**
4. Name it anything (e.g. "Streamlit block trades")
5. Click **Create** → **Download JSON**
6. Rename the downloaded file to `credentials.json`

## 5. First-time authorization (generates token.json)

You'll do this once, locally, using a short Python script (I'll provide this alongside the Streamlit app: `authorize.py`).

1. Put `credentials.json` in the same folder as the app
2. Run `python authorize.py`
3. A browser window opens — sign in with `blocktrades32@gmail.com` and click **Allow**
4. You may see a warning "Google hasn't verified this app" — this is expected for personal/test apps. Click **Advanced** → **Go to [app name] (unsafe)** to proceed. This is safe because it's an app you created yourself, not a third party.
5. The script saves a `token.json` file in the same folder — this is what lets the app read the inbox without you logging in again

## 6. Keep these files safe

- `credentials.json` and `token.json` both grant read access to that inbox
- **Never commit these to GitHub** — the repo includes a `.gitignore` that excludes them automatically, but double-check before pushing
- If this ever gets folded into `newsquawk/henrys-widgets`, these stay local/excluded — the production version would need its own server-side credential handling, which your tech team should set up rather than reusing your personal token

## 7. Deploying via GitHub + Streamlit Community Cloud (no local running needed)

Since you want to run this from GitHub rather than your PC, here's the flow:

1. **Create a new GitHub repo** (private recommended) — call it something like `blocktrades-headlines`
2. Push everything **except** `credentials.json` and `token.json` (the `.gitignore` handles this automatically if you're using git normally)
3. Go to https://share.streamlit.io/ and sign in with GitHub
4. **New app** → pick your repo → set main file path to `app.py` → Deploy
5. Once deployed, go to the app's **Settings → Secrets** (three dots menu, or Manage app)
6. Paste in the contents of your `token.json` file like this:

   ```toml
   gmail_token = '''
   {"token": "...", "refresh_token": "...", "client_id": "...", ...}
   '''
   ```

   (Open `token.json` in a text editor, copy the whole JSON blob, paste it between the triple quotes above)
7. Save — the app will restart and pick up the secret automatically

**Important:** you still need to generate `token.json` once. The easiest way is to run `authorize.py` locally just for this one step (it needs a browser to complete the Google login), then copy its contents into Streamlit's secrets as above and delete the local copy if you like. There's no way to skip this initial local step — Google's OAuth login has to happen somewhere with a browser.

If `token.json`'s refresh token ever expires or gets revoked, you'll need to re-run `authorize.py` locally once and update the Streamlit secret again.
