# Block Trade Headlines Privacy Policy

Last updated: 6 October 2026

Block Trade Headlines is a private workflow tool used to read CME Group block-trade alert emails and convert the trade information into formatted market headlines.

## Google data accessed

The application requests read-only access to the connected Gmail account. It reads CME Group block-trade alert emails so that their trade details can be displayed and formatted.

The application does not send, modify, or delete Gmail messages.

## How data is used

Email data is used only to identify and process CME Group block-trade alerts for the Block Trade Headlines application.

Google user data is not sold, used for advertising, or shared with third parties.

## Data storage

The application may temporarily cache processed Gmail message data to reduce repeated Gmail API requests. This cache is used only for operation of the application.
